# A.1-Kickoff-Setup

Mon Jun 15 · 9:15–10:00 AM · In-person — Valerius Living, Denver · 15m teach / 30m workshop.

Open the week: who we are, how the week works, and get every founder's agent and repo running. Setup only — bootstrap and data ingestion come in A.2.

Founders leave with a basic understanding of the WNCP AI approach (startup vs company, the Build–Measure–Learn loop, PMF), an introduction to CRAFT+ (Collect · Refine · Analyze · Forge · Test · + People/Processes), and a verified agent responding in their cloned repo.

**What you do.** Go to the Notion prep sheet under *Agent Shares*; define what we mean by an agent (a tool that works on your computer and uses files); go around the room — which platform each founder is on, whether they have a GitHub account, and their proficiency tier (Basic / Intermediate / Advanced).

Setup is environment only — bootstrap and data ingestion are A.2, don't start them here. AI principles are taught in A.2, so keep the kickoff light on them. Always say "your agent," never "Claude Code."
