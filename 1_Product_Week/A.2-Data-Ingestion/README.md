# A.2-Data-Ingestion

Mon Jun 15 · 10:00–11:00 AM · In-person

Founders drop all discovery data — interview transcripts, analytics exports, market research notes, field/technical/regulatory docs, any format — into the repo, and the `ingest-sources` skill standardizes it into clean, indexed files the downstream skill chain can read. Founders leave knowing what data they have, what's thin, and what's ready for JTBD extraction.

This folder is the in-session working space. You complete the template **by hand** and it stays here; the agent's derived markdown deliverable goes to `2_Outputs/.agents/<session>/`. Session plan and naming convention: `0_System/spec/Founder OS PRD v1.md`, §A.1.
