# D.1-Demo-Day

Thu Jun 18 · 1:00–2:00 PM (morning open for self-directed prep) · Virtual · ~5 min/person (demo + Q&A).

Close the week: each founder defends the full CRAFT+ chain — jobs → PRD → demo → metrics → AI role — earns superlatives, and leaves with a Sprint 3 commitment and a roadmap start.

**The beats — walk the chain, show the reasoning.** The rubric: JTBD clarity · prioritization · prototype-tests-riskiest-assumption · metrics make sense · AI role defensible. ~5 min/person: demo + Q&A, no script. The closing must land CRAFT+ as a 2–4 week cycle, not a one-week event — the rhythm is the discipline.

**What you do.** Present and defend the chain for ~5 minutes. Superlatives revealed at the close: Best Kill List · Sharpest Pivot · Most Defensible AI · Hardest Question Survived · Crowd Favorite. State your Sprint 3 commitment, one sentence: *"Sprint 3 (date) tests [X] by [Y]."* Receive the Process Card handoff (the one-page CRAFT+ recap).

**Where work goes.** No fixed output path — this is the week close. Roadmapping handoff (Now/Next/Later vs hypothesis roadmap) and the prototype → production bridge (Tier 3 path: spec files + Claude Code on GitHub + Vercel) are introduced at the close.
