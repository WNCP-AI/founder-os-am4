# C.2-Metrics-OKR

Wed Jun 17 · 11:00–12:00 PM · In-person

A one-hour Metrics & OKR Workshop. Founders write 1 Objective and 2–4 Key Results as validation signals for the riskiest assumption in their PRD — not activity counts — with a self-check ("did the bet pay off, or were you just busy?") and an ambition check (target 50–60% hit rate). The output block is formatted to drop directly into PRD v2 §8 (OKRs).

This folder is the in-session working space. You complete the template **by hand** and it stays here; the agent's derived markdown deliverable goes to `2_Outputs/.agents/<session>/`. Session plan and naming convention: `0_System/spec/Founder OS PRD v1.md`, §A.1.
