# A.5-PRD-v1

Mon Jun 15 · 1:30–3:45 PM (shared with A.5-Prototyping-1) · In-person — Valerius Living, Denver · 20m teach / 1h 55m workshop.

Where the work of the morning snaps into a first product document — the **Forge (F)** of CRAFT+. The JTBD output, the value prop, and the persona come in; a minimal five-section PRD comes out, ending in a written prototype commitment. Metrics, competitive analysis, and OKR targets are deferred to later sessions.

**The beats — PRD v1 is intentionally lean.** Five sections only: Company + Value Prop · Target User · Jobs to Be Done · Features · Prototype. If it feels incomplete, that is correct by design — PRD v1 is the Day 1 snapshot. The skill is Socratic — it asks, you answer. The founder does the thinking, the agent does the typing: the morning's work (value prop, persona, ranked jobs) is yours to confirm and sharpen, not to regenerate. Must Haves are capped at three or fewer, each with a "does X — does NOT Y" scope boundary. The Prototype section ends with a written hypothesis ("if I build X, the user will Y") and a 3–5 step happy-path user flow.

**What you do.** Open `A.5-PRD-v1-Template.md` and work through the five sections in order with the `8-draft-prd` skill. In §3 mark the "Prototype focus" job before moving to §4 — this drives the Features and Prototype sections. In §4 surface all features you can think of, then assign Must / Nice / Future priority; confirm Must Haves are three or fewer and each has a scope boundary. In §5 write the hypothesis first, then define the user flow (happy path only, 3–5 steps); capture what you are explicitly not building in the exclusion list.

**Where work goes.** You complete the template by hand and it stays in this folder; the agent's derived markdown deliverable lands in `2_Outputs/.agents/A.5-PRD-v1/PRD-v1.md`; the slimmed essence folds into `0_Company/`.

PRD v1 must be complete before the prototype block starts. The `8-draft-prd` skill must NOT auto-generate the document — it must ask questions and push founder thinking. PRD v2 is a new file rebuilt after the Tuesday 1:1s; do not worry about extensibility today.
