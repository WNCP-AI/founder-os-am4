# C.1-Peer-Court

Wed Jun 17 · 10:00–11:00 AM · In-person

Each founder gets ~6 minutes of strict-timer peer review. Founders present the riskiest assumption in their PRD + prototype (not the whole product), and the cohort returns one highest-signal note per founder. Superlatives collected: Best Visual Demo, Best Vaporware, Most Likely to Crash Their Own Server.

This folder is the in-session working space. You complete the template **by hand** and it stays here; the agent's derived markdown deliverable goes to `2_Outputs/.agents/<session>/`. Session plan and naming convention: `0_System/spec/Founder OS PRD v1.md`, §A.1.
