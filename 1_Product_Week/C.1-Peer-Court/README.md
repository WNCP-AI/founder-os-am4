# C.1-Peer-Court

Wed Jun 17 · 10:00–11:00 AM · In-person — Valerius Living, Denver · 5m frame / 55m peer review.

Each founder gets one high-signal critique from the cohort; the group calibrates on what "good" looks like before the v2 PRD is locked.

**The beats — present the riskiest assumption, not the whole product.** Format: 3-minute demo + 2 questions per founder. Strict timer enforced. One highest-signal note per founder; don't let reviews run long.

**What you do.** Demo for 3 minutes on the riskiest assumption in your PRD + prototype (not the whole product). Take 2 questions from the cohort. Capture the single highest-signal note — the one that most tests the riskiest assumption; that note is the input to the C.3 single highest-signal change.

**Where work goes.** No fixed output path — superlatives revealed at the close: most likely to raise (big venture check based on TAM or traction), most likely to be acquired (idea someone would buy outright), most complicated prototype (would need a PhD-level engineering team), best VC-style question asked. Superlatives are awards, not just labels — make the reveal a moment.
