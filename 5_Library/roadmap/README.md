## Scoring Model

Every initiative (build or test) is scored:

- **Impact (1–5):** value delivered if this works, grounded in specific customer signals
- **Confidence (1–5):** certainty it is the right thing, sourced from PRD v2 Section 7 (H→5, M→3, L→1)
- **Effort (1–5):** real cost given actual team, skills, and available hours — not best-case capacity
- **Score:** `(Impact × Confidence) / Effort` — higher = higher priority
- **Risk flag:** if Confidence = 1 AND Impact ≥ 4, auto-elevate to Now regardless of Score

Cap Now at 2–3 items. The board runs on a founder-defined cycle with a fixed review date.

## Pipeline Position

```
value-prop → JTBD → PRD v1 → PRD v2 (OKRs) → Roadmap (Now/Next/Later) → Sprint 3+ cycles
```

The roadmap is the last link in the CRAFT+ chain — it converts PRD outputs into a repeatable sprint cycle founders run with their team indefinitely.
