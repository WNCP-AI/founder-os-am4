# Claude Code

Anthropic's AI coding agent for your terminal — reads your whole codebase, edits files, and runs commands autonomously.

- **Pricing:** Requires Claude Pro ($20/mo) or API credits. New API accounts get ~$5 in free credits at platform.anthropic.com.

**5-Step Quickstart**
1. Sign up or log in at claude.ai — subscribe to Pro, or get API credits at platform.anthropic.com
2. Install the CLI: `npm install -g @anthropic-ai/claude-code`
3. Run `claude` in your project directory — it reads your codebase automatically
4. Describe your task: 'Build a scam-detection API endpoint that scores text messages 0–100'
5. Review changes with `git diff` before accepting — Claude shows every file it edits
