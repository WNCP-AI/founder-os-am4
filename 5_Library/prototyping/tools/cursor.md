# Cursor

An AI-first code editor (VS Code fork) — chat with your whole codebase, accept multi-line autocompletes, and let an agent edit files end-to-end.

- **Pricing:** Hobby plan: free, no credit card. Pro: $20/mo for unlimited Tab completions and extended Agent usage on frontier models.

**5-Step Quickstart**
1. Go to cursor.com, click Download, and install the app for your OS (Mac, Windows, or Linux)
2. Open Cursor and sign in with Google, GitHub, or email — the Hobby tier is free, no credit card needed
3. Open a folder (existing repo or an empty one) — Cursor indexes the codebase so the AI can answer questions about it
4. Press ⌘L (Mac) or Ctrl+L (Windows/Linux) to open chat — ask for an edit, e.g. 'Create index.html with a scam-text scoring form that calls a /score endpoint'
5. Review the proposed diff, click Apply to write the files — then press ⌘K / Ctrl+K on any line to inline-edit it in plain English
