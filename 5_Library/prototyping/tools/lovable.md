# Lovable

Build full-stack web apps by describing them in plain English — no code required. Goes from prompt to live URL in minutes.

- **Pricing:** Free plan: 5 daily credits (30/month). Paid plans from $25/mo.

**5-Step Quickstart**
1. Go to lovable.dev and sign up with GitHub or Google
2. Click 'New Project' and describe your app in one sentence — e.g. 'A scam detector where users paste a suspicious text'
3. Lovable generates a working React app with a live preview — review it
4. Iterate in plain English: 'Add a results page', 'Make the button red'
5. Click 'Publish' for a live URL — or connect your GitHub repo to deploy to Vercel
