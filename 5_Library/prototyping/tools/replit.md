# Replit

Browser-based coding environment with an AI Agent that writes, runs, and deploys your app from a plain-language description.

- **Pricing:** Free Starter plan includes daily Agent credits and ability to publish one app. Core plan ~$25/mo for full Agent access.

**5-Step Quickstart**
1. Sign up at replit.com/signup with GitHub, Google, or email
2. Click 'Create Repl' and choose a template — or start blank and describe your app to the AI Agent
3. Tell the Agent what to build: 'A privacy audit tool that checks what data apps can access'
4. The Agent writes code, installs packages, and shows you a live preview — chat to refine
5. Click 'Deploy' to get a public URL — Replit hosts it for you
