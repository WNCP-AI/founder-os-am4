# Bolt

StackBlitz's AI full-stack builder — describe your app and get running, editable code in the browser instantly. No install needed.

- **Pricing:** Free tier: ~150K tokens/day. Paid plans from ~$20/mo.

**5-Step Quickstart**
1. Go to bolt.new and sign in with GitHub or Google (StackBlitz account)
2. Type your app idea in the prompt bar — e.g. 'A career path recommender with skill gap analysis'
3. Bolt writes and runs the code in-browser — you see the app live on the right
4. Edit by chatting: 'Add a dark mode toggle', 'Fix the mobile layout'
5. Click 'Deploy' to publish to Netlify or connect to GitHub for Vercel
