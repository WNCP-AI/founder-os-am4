# OpenAI Codex

OpenAI's AI coding agent — available as a cloud tool at chatgpt.com/codex, open-source CLI, or IDE extension.

- **Pricing:** Free ChatGPT account gives basic CLI access. Cloud features (GitHub review) require Plus ($20/mo). CLI is open source and free to install.

**5-Step Quickstart**
1. Sign up at chatgpt.com or log in — free account works for the CLI
2. Install the CLI: `npm i -g @openai/codex` (open source, Apache 2.0)
3. Run `codex` in your project directory and describe what you want to build
4. Or use the cloud interface at chatgpt.com/codex — connect your GitHub repo for PR review
5. Review and accept the generated changes, then push or deploy as normal
