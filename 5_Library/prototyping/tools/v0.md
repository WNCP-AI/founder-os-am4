# v0

Vercel's AI component generator — describe any UI in plain English and get production-ready React + Tailwind + shadcn/ui code to paste into your Next.js project.

- **Pricing:** Free plan: $5 in monthly credits. Premium from $20/mo for $20 in credits, Figma imports, and API access.
- **Note:** Pairs well with Lovable / Bolt for UI-heavy prompts.

**5-Step Quickstart**
1. Go to v0.dev and sign in with your Vercel account, GitHub, or email
2. Describe the UI you want — e.g. 'A pricing page with three tiers and a toggle for monthly/yearly billing'
3. v0 generates a live React component — review the preview and iterate by chatting: 'Add a dark mode variant', 'Use a card layout'
4. Click the copy button to grab the generated code, or use 'Deploy to Vercel' for a live URL
5. Paste the component into your Next.js project and run `npx shadcn@latest add` for any missing dependencies
