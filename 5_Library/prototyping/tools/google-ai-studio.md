# Google AI Studio

Free browser-based access to Google's Gemini models — prototype, generate API keys, and deploy without a credit card.

- **Pricing:** Free. Gemini Flash ~15M tokens/day. No credit card required.

**5-Step Quickstart**
1. Go to aistudio.google.com and sign in with any Google account
2. Click "Get API Key" in the left sidebar — create a new project key
3. Open a new prompt and select Gemini 2.0 Flash from the model dropdown
4. Write a system prompt and test with a few sample inputs in the chat panel
5. Click "Get code" to export working Python, JavaScript, or cURL when ready
