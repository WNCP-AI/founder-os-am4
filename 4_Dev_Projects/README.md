# 4_Dev_Projects — Dev & Build Projects

Anything with its own repo or that gets built into a product. The natural continuation after
the pipeline ends: the PRD is done, the OKRs are set — now build. Each project in its own
subfolder, named `YYYY.MM Short Name` (e.g. `2026.06 Prototype Sprint 1`), with its own
README and internal structure.

Use for:
- The prototype built in A.5 (fed by the PRD in `2_Outputs/.agents/A.5-PRD-v1/PRD-v1.md`)
- MVPs, apps, tools, and experiments you're actively building
- Projects that may eventually get their own standalone repo

**Rule:** founders running builds in parallel to the program work here and keep Founder OS as
the operating layer above the code. If a project outgrows this folder (large codebase, team
contributors), it graduates to its own repo — link back from here.
